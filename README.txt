ORIGINE — Static Restaurant Website
================================

This is a production-style HTML/CSS/JavaScript portfolio project.

FILES
-----
index.html        Home page
menu.html         Menu with category filters + ingredient/taste/allergen details
story.html        Restaurant story, chef profile and timeline
gallery.html      Responsive visual gallery
reservation.html  Validated reservation form + success state
contact.html      Contact information, map placeholder and contact form
style.css         Shared responsive design system
script.js         Navigation, animations, filtering, forms and UI interactions
assets/            Supplied reference image

HOW TO RUN IN VISUAL STUDIO CODE
--------------------------------
1. Extract the ZIP.
2. Open the extracted folder in Visual Studio Code.
3. Open index.html.
4. Best option: install the "Live Server" extension and click "Go Live".
5. The site works as a multi-page static website with no build step.

NOTES
-----
- The dish and restaurant content is fictional and intended for a portfolio project.
- Images are loaded from Unsplash URLs and therefore require internet access.
- The supplied reference image is included locally in assets/reference-dish.png.
- The reservation/contact forms demonstrate front-end validation and success states.
- Replace the fictional address, phone, email and image URLs before using commercially.
